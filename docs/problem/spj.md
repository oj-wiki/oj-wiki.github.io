# SPJ

SPJ （Special Judge） 是特殊的判题机制，通常应用于不止一个正确答案，或者输出格式可能有区别，或者浮点数精度可能有差别的情况。

## 工作方式

checker 通常读取测试输入、选手输出和标准答案（具体参数顺序依 OJ 而异），再返回正确、错误或部分分数。它适用于多解问题、允许误差的数值答案、非固定格式输出，以及需要按答案质量评分的题目。若只需忽略空格或行末换行，应优先使用平台内置比较器，避免为简单格式差异维护自定义程序。

## 编写与部署

- 按目标 OJ 的协议读取参数和文件；协议、退出码及部分分数格式并无统一标准。
- 严格解析选手输出，处理缺失字段、非法数值、额外内容和极端输入；不可把解析失败当作正确。
- 对浮点误差明确采用绝对误差、相对误差或两者组合，并说明 NaN、无穷大和边界值的处理。
- 将 checker 视为可能出错的程序：限制运行时间、内存和文件访问，避免依赖不受信任的文件路径。
- 用正确输出、典型错误输出、边界值、截断文件和恶意超长输入回归检查；记录 checker 版本。

SPJ 只能判定它实际检查的属性；若 checker 本身有漏洞，可能接受错误答案或拒绝正确答案。接口细节应以目标平台文档为准。
