# 题目

通常来说，题目是在线评测系统的最小评测单元。题目可按选手提交内容和评测交互方式区分，具体差异见[题型与评测模式](category.md)：

- 标准程序题（可配置标准输入输出或文件 IO）
- 交互题
- 提交答案题
- SPJ、自定义 checker 和子任务等可组合的评测/计分模式
- 通信题、函数补全题等由 grader 或交互协议实现的题目形态

各题型的输入输出约定见[题型说明](category.md)。

题目通常需要包含以下内容：

- 题目标题，描述，以及元数据
- 输入输出说明
- 时空限制
- 输入输出文件已经评测设置
- 评测所需的附加文件

题目元数据的组织方式见[元数据说明](metadata.md)。

题目通常由多个评测点构成，评测点是评测系统的最小执行单元。评测点可以拥有以下属性：

- 可见性
- 分数
- 输入输出文件
- 评测方式

评测设置通常可以定义以下评测行为：

- SPJ
- 评测点分数

测试文件组织与质量检查见[测试数据](test-data.md)，得分汇总方式见[记分策略](scoring.md)。需要自定义答案比较时可使用 [SPJ](spj.md)；题目迁移可参考[交换格式](exchange-format.md)，数据生成与校验工具见 [testlib](testlib.md)。
