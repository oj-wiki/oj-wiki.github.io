# 交换格式

题目交换包用于在本地开发工具、题库和 OJ 之间迁移题目。不同平台的目录约定和字段名称并不完全兼容，导入时应检查目标平台对题型、checker、文件名和计分规则的支持。

## 建议包含的内容

- 题目元数据：标题、来源、标签、时间/内存限制、输入输出文件名和题型。
- 题面：描述、输入输出格式、样例、数据范围及评分说明。
- 测试点：输入、标准输出、分组及分值配置。
- 附加文件：checker、交互器、验证器、生成器或题目运行所需资源。
- 可选材料：参考解、题解和生成数据所需的说明。

## 导入与导出检查

导出时应使用稳定目录结构和明确编码，并避免打包缓存、个人密钥或无关构建产物。导入后核对文件清单、样例显示、限制、测试点配对、可执行权限和 checker 行为；再运行样例及完整评测确认结果一致。

参考格式可采用 [Kattis Problem Package Format](https://www.kattis.com/problem-package-format/)；该格式并不意味着所有 OJ 都能无损互通。迁移工具应报告不支持或被转换的字段，避免静默丢弃信息。
