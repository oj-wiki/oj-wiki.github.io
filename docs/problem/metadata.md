# 题目元数据

题目元数据通常包含

- 描述
  - 题目描述
  - 输入格式
  - 输出格式
  - 样例输入 / 输出 / 解释
  - 数据范围
  - 评分方式
- 评测配置
  - 输入输出文件名 / 使用标准输入输出
  - 数据点配置
    - 时间限制
    - 内存限制
    - 记分方式
  - 编程语言限制
- 其他元数据
  - 标签
  - 作者
  - 来源
  - 难度

## 设计与校验

把面向选手的题面内容与评测端配置分开管理。题面描述、输入输出格式、样例和数据范围应能独立呈现；评测配置则需要明确输入输出文件名、时间/内存/输出限制、语言白名单、checker、数据点和计分规则。不要把内部答案、隐藏测试数据路径或管理备注暴露在公开题面元数据中。

为题目及其评测配置记录稳定标识和版本。修改测试数据、checker、限制或计分规则时，应保留变更记录，并决定是否需要重测已有提交。不同 OJ 使用的字段名称和默认值各不相同，导入题目时应检查缺省值、单位、文件名大小写和不支持字段，而不是假设配置会自动等价转换。

发布前至少核对：样例能通过；输入约束与数据相符；测试点文件成对且命名唯一；总分和子任务依赖一致；时空限制在目标评测环境中测量；题面没有泄露隐藏数据或答案。文件布局与数据检查见[测试数据](test-data.md)，迁移时见[交换格式](exchange-format.md)。
