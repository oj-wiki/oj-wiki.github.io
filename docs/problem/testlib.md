# testlib

可以编写

- Generator：数据生成
- Validator：数据验证
- Interactor：交互器，用于交互题
- Checker：验证器，用于 SPJ

testlib 是常用于信息学竞赛题目开发的 C++ 头文件库。它提供随机数生成、输入校验、交互器和 checker 等辅助接口；具体 API 会随版本更新，使用时应固定版本并查看对应头文件及官方说明。

## 常见工作流

1. 用 generator 生成覆盖边界和随机结构的数据，并固定随机种子以便复现。
2. 用 validator 检查每个输入是否满足题目约束；验证器应拒绝多余字符、越界值和不完整输入。
3. 用可信参考解生成标准输出，再运行正确解和针对性错误解确认数据有效。
4. 交互题使用 interactor 定义消息协议、合法动作和结束条件；注意双方缓冲区刷新与超时行为。
5. 多解或部分分题目可编写 checker，明确容差、非法输出和分数返回规则。

生成器、验证器和 checker 也应在隔离环境中运行。提交数据包时包含必要的源文件、构建说明和版本信息，不要只保留无法复现的生成结果。
