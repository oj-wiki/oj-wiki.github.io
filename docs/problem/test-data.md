# 测试数据

测试数据用于复现题目要求并判定提交。标准输入输出题通常为每个测试点准备输入文件和对应的期望输出；评测机按题目配置启动程序、传入输入，再使用标准比较器或 checker 判定输出。

## 组织方式

- 每个测试点应有稳定且唯一的标识，输入与输出应正确配对。
- 将样例与正式测试数据区分开。样例用于题面展示，不应意外泄露隐藏数据。
- 多文件题、交互题或特殊评测题还可能需要资源文件、交互器、checker 等附加文件。
- 若测试点分组或存在依赖关系，应在题目配置中明确分组、依赖和计分方式。

## 质量检查

数据应覆盖边界、极端规模、退化情况及容易出错的情形；生成后运行 validator 检查输入约束，并用可信参考程序生成答案。发布前可用正确解和针对性错误解回归，检查数据是否能区分预期行为。

时间、内存限制应在目标评测环境中测量，并考虑编译器和机器差异。更新数据或 checker 后，应保存版本记录并重新评测受影响的提交。
