# GO 编译器

[GO 编译器](https://go.dev) 通常以不同版本作为区分。

编译命令为：

```sh
go build -o foo foo.go
```

可以使用 `-p 1` 命令行参数，或者 `GOMAXPROCS=1` 环境变量限制并行度来减少多线程编译对系统的影响。

编译结果文件为 `foo`：

```sh
./foo
```

需要注意的是， GO 编译器需要编译缓存，可以使用 `GOCACHE=/tmp` 等指定一个可写入目录。

## OJ 配置要点

编译器版本会影响语言特性和标准库行为，评测平台应公开 Go 版本并固定评测节点的工具链。不要把 `GOMAXPROCS` 当成运行程序的 CPU 时间限制；它限制 Go 运行时可并行执行的线程数，真正的时间和内存限制应由沙箱设置。

若使用模块依赖，应禁止评测时访问公网，并在可控构建环境中提供依赖缓存或仅允许标准库。执行阶段应明确工作目录、环境变量及输入输出方式，并清理编译缓存和临时文件。
