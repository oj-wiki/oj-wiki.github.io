# Rust 语言编译器

[Rust](https://www.rust-lang.org) 作为编译型语言，拥有官方提供的编译器实现。

编译命令为（文件名为 `foo.rs`）：

```sh
rustc -O -o foo foo.rs
```

生成的可执行文件为 `foo` 可直接运行。

在只读或受限工作目录中，可设置 `TMPDIR` 指向可写临时目录；具体临时目录和缓存行为取决于 Rust 工具链及运行环境。评测端应为编译过程提供可写且有空间上限的工作区。

## OJ 配置要点

Rust 编译器版本决定可用语言特性和标准库版本，应在平台上固定并公开。若提交包含 Cargo 项目，应限制依赖来源并在隔离网络环境下构建；不要允许评测任务任意下载 crate 或运行构建脚本访问外部服务。

编译阶段和运行阶段需要分别计量资源。优化编译可能耗时较长，应有编译超时与临时磁盘配额；执行生成的二进制时仍需按题目配置限制时间、内存、进程和文件访问。
