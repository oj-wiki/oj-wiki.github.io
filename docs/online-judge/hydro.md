# Hydro

[Hydro](https://github.com/hydro-dev/Hydro)（又称 vj5）是一个模块化的信息学在线评测平台，包含 Web 应用、评测调度和评测机等组件。项目使用 Node.js/TypeScript 生态，官方仓库提供安装、管理、插件开发与题库导入文档。

## 特点

- **插件扩展**：通过插件扩展功能，减少直接修改核心代码带来的升级冲突。
- **多空间与权限**：一个实例可以管理多个相对隔离的教学或竞赛空间，并细分用户、题目、作业和比赛权限。
- **多种使用场景**：支持题库练习、作业，以及 OI、IOI、ICPC 等常见赛制。
- **题型与导入**：除标准输入输出外，支持 Special Judge、交互等题型；提供多种题库导入和外部平台题目引用能力，具体兼容范围见官方文档。
- **分布式评测**：可连接多个评测节点；节点需要配置相应语言运行环境，并按 Hydro 的协议与题目数据管理方式工作。

## 组件与评测流程

Hydro 的核心服务负责用户、题目、提交、权限和任务调度；评测节点负责领取任务、运行评测并回传结果。部署多个节点时应分别规划核心服务、数据库/文件存储和评测节点的网络连通性，并确保题目数据在节点可用。评测节点是执行不可信代码的边界，应按官方建议隔离权限、限制网络与资源。

## 部署与运维

官方提供安装脚本和文档，支持的发行版、运行时和升级路径会随版本变化。请按[官方文档](https://hydro.ac/docs/)安装，不建议直接复制历史博客中的命令。

重点运维事项：

- 定期执行并验证备份/恢复，备份范围需覆盖数据库及题目、附件等持久化文件。
- 评测节点安装所需编译器和运行时，并单独校验沙箱能力与资源限制。
- 升级前阅读发行说明，先在测试环境验证插件和题库兼容性。
- 对外提供服务时配置 HTTPS、邮件、可信代理和访问控制；不要将数据库或内部评测接口暴露到公网。
