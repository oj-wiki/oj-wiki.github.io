# DMOJ

[DMOJ](https://github.com/DMOJ/online-judge) 是开源题库与竞赛平台，常用于练习站和大型竞赛。项目由网站应用和独立评测后端组成：网站管理题目、用户、提交与比赛；[judge-server](https://github.com/DMOJ/judge-server) 连接站点、执行评测并回传结果。评测机可以部署在多台机器上，以增加并行评测能力。

## 主要能力

- 支持大量语言运行时，并允许按题目/语言配置资源限制。
- 支持标准题、交互题、函数/签名题、生成器和自定义 checker 等评测方式。
- 提供 ICPC、IOI、AtCoder 等常见竞赛规则、虚拟参赛、封榜及系统测试能力。
- 评测服务独立部署，适合将 Web 服务与不可信代码执行节点分开扩展。

## 一次评测

用户提交由网站保存并进入评测调度；站点通过 bridge 与评测机通信，评测机取得代码和题目数据后，选择语言执行器编译并在沙箱中运行各测试点，最后将状态和分数回传。站点和评测机各有自己的配置与日志，排查问题时应先判断故障发生在队列/bridge、题目数据、语言执行器还是沙箱。

## 部署考虑

DMOJ 的部署由网站端、数据服务、事件/实时更新服务和一个或多个评测节点构成。组件与依赖会随版本更新，按[官方安装文档](https://docs.dmoj.ca/#/site/installation)配置，不要把旧版教程里的依赖版本或配置直接用于新系统。

评测机需准备对应的编译器和运行时，并校验内核、沙箱依赖、权限及资源限制。judge-server 提供 `dmoj-cli` 用于在本机检查题目和执行评测；适合在把题目部署到线上前验证题目配置、checker 和运行环境。
