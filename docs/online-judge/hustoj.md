# HUSTOJ

[HUSTOJ](https://github.com/zhblue/hustoj) 是基于 PHP、C++、MySQL 和 Linux 的开源 OJ，长期用于 ACM/ICPC 与 NOIP/OI 训练、校内题库和比赛。项目包含 Web 前端、判题服务与安装/升级工具，并提供题库导入导出和多种部署方式。

## 组件与适用场景

Web 端负责用户、题目、提交和比赛管理；独立判题进程从服务端领取任务，在本机编译运行代码并回传结果。判题服务可与 Web/数据库部署在不同机器上。HUSTOJ 的特点是部署门槛相对低、运行环境要求较传统，适合学校或培训环境搭建练习站；扩容和安全隔离能力应按实际版本及部署方式评估。

## 部署与维护

项目持续更新，安装脚本、发行版支持和可选功能可能变化。请跟随[当前仓库 Wiki](https://zhblue.github.io/hustoj/)中的安装和升级说明，不要把旧版教程的系统路径或数据库命令直接用于新版本。执行自动安装或升级脚本前应阅读脚本内容，并先备份数据库、题目数据和本地改动。

把判题节点作为运行不可信代码的独立安全边界：使用低权限账号，限制网络和文件系统访问，并在目标系统上验证超时、内存、进程和文件限制。若启用仓库中依赖外部 API 的可选功能，应自行配置凭据并评估数据发送范围。
