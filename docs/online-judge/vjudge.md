# VJudge（Virtual Judge）

[VJudge](https://vjudge.net/) 是一个面向算法竞赛训练的虚拟评测/虚拟比赛平台。用户可以把来自多个题库的题目组合成训练或虚拟比赛，并在 VJudge 中提交；系统再把提交转发给对应的上游 OJ，并汇总评测状态和榜单。

## 与自建 OJ 的区别

VJudge 主要解决跨题库组织训练和比赛的问题，本身不是可直接替代 Hydro、DMOJ 或 QDUOJ 的自建平台，也不拥有其收录题目的全部题面、测试数据或评测环境。远程提交实际依赖上游网站的账号、接口和规则；上游变更、限流或维护都可能影响评测。

## 使用时注意

- 参加远程评测前，确认题目来源、比赛规则和代码公开设置符合上游 OJ 的规定。
- 上游评测结果使用的是上游语言版本、编译参数和资源限制，可能与本地平台不同。
- 练习/比赛榜单是跨站汇总结果；若需要稳定、可审计的正式赛事环境，应优先使用赛事主办方指定的平台。
- VJudge 是在线服务；本页未找到官方公开的完整服务端源码仓库。不要将 GitHub 上名字相近的个人虚拟评测项目误认成 VJudge 官方实现。
