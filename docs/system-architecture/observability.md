# 可观测性

可观测性帮助运维人员发现服务故障、排队积压和评测异常。指标、日志和追踪应共享提交 ID、任务 ID、节点 ID 等关联字段，同时避免记录用户源码、密码、令牌或完整敏感数据。

## 建议监控

- **用户请求**：请求量、延迟分位数、错误率及数据库连接池使用率。
- **队列**：等待任务数、最老任务年龄、排队到启动的延迟、重试与死信数量。
- **评测节点**：在线数量、任务吞吐、编译/运行耗时、资源使用和异常退出数。
- **存储**：数据库容量与慢查询、对象存储使用量、下载失败和缓存命中率。
- **比赛体验**：提交状态更新延迟、榜单刷新延迟、澄清请求积压。

为关键指标设置与用户影响相对应的告警，例如持续增长的最老任务等待时间，而不是只对瞬时峰值告警。日志要有保留和访问控制策略；任务追踪可连接后端创建、队列领取、评测和结果回传各阶段。告警应指向清晰的排查步骤和责任服务。
