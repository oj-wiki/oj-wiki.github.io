# 前端

前端为参赛者、出题者、比赛管理员和站点运维人员提供界面。它负责展示和收集信息，权限与业务规则仍须由后端重新校验，不能依赖隐藏按钮或浏览器校验来保护数据。

## 主要页面与状态

- 用户注册、登录、资料和权限管理。
- 题目浏览、题面展示、代码编辑与提交状态查询。
- 比赛报名、比赛题目、实时或封榜榜单、公告与澄清。
- 管理端的题目、测试数据、语言、比赛和用户配置。

提交页应展示排队、编译、运行和结束状态，并处理页面刷新、重复提交及网络断开。实时榜单等数据可通过轮询、SSE 或 WebSocket 更新；需要明确更新频率、失败重连和封榜时对不同角色显示的规则。

## 接口和安全

前端与后端应使用版本明确的 API 契约，处理分页、错误码和向后兼容。服务端必须校验对象归属和操作权限，并对用户提供的题面、公告、编译输出等内容进行安全编码，避免脚本注入。部署时还要正确配置 HTTPS、跨域策略、可信代理与静态资源缓存。业务数据流见[后端](back-end.md)。
