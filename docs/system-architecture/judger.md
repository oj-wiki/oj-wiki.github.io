# 评测机

评测机负责实际编译和运行提交代码。它是系统中执行不可信输入的组件，应与 Web 服务和数据库隔离，并在本机对提交程序、编译器及 checker 施加资源与访问限制。

## 典型工作流

1. 通过认证通道领取任务，并校验任务 ID、题目版本和超时策略。
2. 获取提交代码、题目配置和测试数据；校验文件清单与内容摘要。
3. 在隔离工作区中按指定语言和参数编译；编译器本身也应受资源限制。
4. 对每个测试点创建受限进程，准备输入和附加文件，执行程序并收集输出、退出状态和资源用量。
5. 使用标准比较器或 checker 汇总结果，清理进程、临时文件和 cgroup 后回传结果。

任务需要能安全取消和重试。评测机重启后不应遗留可运行的用户进程；回传失败时应保留有限的任务状态并重试，后端则按任务版本去重。运行环境、语言版本和编译参数应记录下来，便于复现结果。

评测机不应拥有访问数据库、云凭据或其他评测节点的权限。队列交互见[评测队列](queue.md)，沙箱机制见[代码执行](../judge/sandbox/)。
