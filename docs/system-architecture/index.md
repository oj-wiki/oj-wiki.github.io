# 系统架构

在线评测系统通常以网页的形式提供服务。用户请求由前端和业务后端处理，提交随后进入评测队列，由评测机执行并回传结果。数据库保存结构化业务状态，文件存储保存代码、题目数据和附件；缓存用于会话及可重建的热点数据。

- 前端
- 后端
- 任务调度：排队、优先级、公平性、重试和负载分配
- 数据库
- 消息队列
- 文件存储

一次评测通常经过：提交写入持久化存储 → 创建任务并排队 → 调度器分配评测机 → 评测机获取代码、题目配置和测试数据 → 在隔离环境中编译运行 → 结果写回并更新提交与榜单。队列消息与数据库状态需要协调，避免任务丢失或重复执行；评测任务应设计为可重试，并通过提交 ID、任务版本等信息保证结果可追踪。
